# Assumer — issues

This is the public issue tracker for [Assumer](https://assumer-web.pages.dev), an AI coding agent that runs in your terminal, in a desktop app, or in your browser.

Assumer's source is not public. This repository exists so you have somewhere to report bugs and request features without needing access to it.

## Reporting a bug

[Open a bug report.](https://github.com/4BornGithub/assumer-issues/issues/new?template=bug-report.yml)

The crash screen in the terminal app can do this for you: it opens a report with your version, operating system, terminal and the stack trace already filled in.

If you are reporting by hand, the two things that make a report actionable are the exact version you are running and what you were doing when it happened.

## Requesting a feature

[Open a feature request.](https://github.com/4BornGithub/assumer-issues/issues/new?template=feature-request.yml)

Describe the problem you ran into rather than the solution you have in mind. It is usually the more useful half, and it leaves room for a better answer than either of us had first.

## Security

**Do not open an issue for a security problem.** Report it privately through [GitHub's security advisory form](https://github.com/4BornGithub/assumer-issues/security/advisories/new) so it can be fixed before it is public.
